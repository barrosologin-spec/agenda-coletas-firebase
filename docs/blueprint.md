# **App Name**: JFab Coleta Fácil

## Core Features:

- Autenticação JFab: Tela de login com Firebase Authentication para diferentes níveis de acesso (administrador, operador, motorista, cliente).
- Agendamento JFab: Formulário para agendamento de coletas com campos para cliente, endereço, data/hora, quantidade de unidades, quantidade de pallets, valor estimado e observações.
- Rotas JFab: Visualização de rotas de coletas do dia, filtradas por motorista, com a possibilidade de alterar o status (em andamento, finalizado, cancelado).
- Notificações JFab: Central de notificações interna para alertas sobre novas coletas, mudanças de status ou alterações nas rotas. Exibição em tempo real sem recarregar a página.
- Dashboard JFab: Dashboard interativa com estatísticas de coletas (pendentes, concluídas, canceladas, por rota, por motorista), gráficos e filtros por período.
- Filtros JFab: Sistema de busca e filtros para todas as listas (coletas, rotas, usuários, etc.).
- Logs JFab: Logs de atividades para rastrear quem criou, alterou ou excluiu agendamentos.

## Style Guidelines:

- Cor primária: Vermelho vibrante (#E53935) para destacar a identidade visual.
- Cor de fundo: Vermelho suave e dessaturado (#F2E9E9).
- Cor de destaque: Laranja vibrante (#FB8C00) para botões de ação e elementos interativos.
- Fonte para corpo do texto e títulos: 'PT Sans' (sans-serif) para um visual moderno e legível.
- Ícones claros e intuitivos, alinhados ao tema de coleta e logística.
- Layout responsivo e limpo, com componentes como cards, tabelas interativas e modais.
- Animações sutis para feedback visual em ações como carregamento e atualização de status.
